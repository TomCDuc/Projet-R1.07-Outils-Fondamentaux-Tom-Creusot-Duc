## 📌 Description
Ce projet implémente un **solveur de Sudoku** utilisant :
- **Représentation matricielle** de la grille (9x9).
- **Algorithme de backtracking** (avec et sans optimisation).
- **Benchmark** pour comparer les performances.
- **Générateur de grilles** aléatoires.

**Notions du module exploitées** :
✅ **Matrices** (stockage et manipulation de la grille).
✅ **Backtracking** (recherche avec retour arrière).
✅ **Optimisation** (réduction de l'espace de recherche).
✅ **Complexité algorithmique** (analyse O(n!) vs O(n^2)).
